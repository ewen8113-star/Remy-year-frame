### 4. 物资归还日期（北京时间）

**问题**：场次 `N220630-RC-PHD 260519福州PHD晚宴` 归还登记后，入库日期显示少一天（API 将 MySQL `DATE` 序列化为 UTC ISO，前端 `slice(0,10)` 得到 `2026-05-20`，实际业务日为 5 月 21 日）。

**文件**：`src/routes/inventory.js`、`public/app.js`、`src/lib/businessTime.js`（复用）

- 归还/入库默认日期改为 `todayYmd()` / `todayDateInputValue()`，不再用 `toISOString().slice(0,10)`。
- 入库台账 API 返回 `return_date` 统一为北京时间 `YYYY-MM-DD`（`jsonYmd`）。
- 列表、详情、月份筛选、空瓶追溯时间展示统一 `fmtDate` / `invBusinessYmd`。

### 5. 活动报价预览版式交互（Excel 式列宽 + 持久化）

**文件**：`public/activity-quotes.js`、`public/style.css`

- 去掉大块数字输入网格，改为顶部**紧凑工具栏**（PDF 纸张方向、行高、重置）。
- 预览表表头支持**拖拽列线**调整列宽（相邻列联动，实时预览）。
- 列宽 / 行高 / 纸张方向写入 `localStorage`（`remy_aq_export_layout_v1`），按子报价单 ID 记忆；再次进入同场次 Sheet 可恢复（如说明列 42→20）。
- 预览区布局：工具栏固定高度，表格区域 `aq-preview-table-stage` 可滚动，便于边调边看效果。
